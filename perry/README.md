# perry/

Perry apps that use qt2wasm components. Not part of `qt2wasm build`: Perry is a
separate tool that lives in this repo (recipes/perry, recipes/perry-component-host).

- `counter/`: a native GTK4 window (perry/ui) driving the Qt Counter QObject.
  The qt2wasm component runs unmodified on wasmtime through Perry's
  `perry/component` module (libperry_component_host.a from the
  perry-component-host package), with typed bindings generated by `perry-wit`
  from the component's WIT. `cd counter && pixi run smoke`, then `pixi run app`.
