Import interface demo:counter/counter-events@0.1.0¶

Signals of Counter, delivered to the host as calls.

Functions¶

value-changed: func¶

Emitted when the count changes to value.

Params¶
  • source: u32
  • value: s32

overflowed: func¶

Emitted instead of stepping past INT_MAX: why says why and at is the value the step would have reached.

Params¶
  • source: u32
  • why: string
  • at: s64

Import interface demo:counter/types@0.1.0¶

Qt value types, records from Q_GADGETs, and Q_ENUM/Q_FLAG enums.

Types¶

enum mode¶

How step advances the value.

Q_ENUM Counter::Mode.

Enum Cases¶

  • linear

    Add one.

  • doubling

    Double the value (zero becomes one).

Export interface demo:counter/counter@0.1.0¶

Types¶

type mode¶

mode

resource counter¶

A counter that steps by one or doubles.

The doc comments in this file are qdoc's. qt2wasm runs qdoc over the project and writes them into the generated WIT as /// docs.

Functions¶

[constructor]counter: func¶

Creates a counter at zero in Linear mode.

Return values¶
  • own<counter>

[method]counter.id: func¶

Instance id; signals from this instance carry it as source.

Params¶
  • self: borrow<counter>
Return values¶
  • u32

[method]counter.value: func¶

This property holds the current count.

Setting it records the new value in history and emits value-changed.

Q_PROPERTY read: Counter::value

Params¶
  • self: borrow<counter>
Return values¶
  • s32

[method]counter.set-value: func¶

Sets value.

This property holds the current count.

Setting it records the new value in history and emits value-changed.

Q_PROPERTY write: Counter::setValue

Params¶
  • self: borrow<counter>
  • value: s32

[method]counter.describe: func¶

Returns prefix followed by the value and the mode, for example "n=3 (linear)".

Params¶
  • self: borrow<counter>
  • prefix: string
Return values¶
  • string

[method]counter.history: func¶

Returns the last n values the counter held, oldest first.

Params¶
  • self: borrow<counter>
  • n: s32
Return values¶
  • list<f64>

[method]counter.set-mode: func¶

Switches to mode m for the next step.

Params¶
  • self: borrow<counter>
  • m: mode

[method]counter.step: func¶

Advances the counter once, by the current Mode.

See also: set-mode, overflowed.

Params¶
  • self: borrow<counter>
