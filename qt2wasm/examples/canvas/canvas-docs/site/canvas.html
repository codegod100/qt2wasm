record size¶

QSize.

Record Fields¶
  • width: s32

record stroke¶

How the outline of a shape is drawn.

Q_GADGET Stroke.

Record Fields¶

  • color: rgba

    This property holds the outline colour. The default is black.

  • width: f64

    This property holds the outline width in pixels. The default is 1.

enum shape¶

The shapes shape can draw.

Q_ENUM Canvas::Shape.

Enum Cases¶

  • box

    A rectangle with rounded corners.

  • ellipse

    An ellipse filling the rectangle.

  • star

    A five-pointed star centred in the rectangle.

flags text-options¶

Styles for text; combine them as flags.

Q_FLAG Canvas::TextOptions.

Flags members¶

  • bold:

    Bold weight.

  • italic:

    Italic.

  • underline:

    Underlined.

resource canvas¶

An RGBA image you draw shapes and text on with QPainter.

The example shows QtGui inside a WASI component: QPainter and QFont draw into a QImage, and the host gets the pixels back as a record from image. Every drawing call emits painted with the area it changed.

[method]canvas.clear: func¶

Fills the whole canvas with background.

Params¶
  • self: borrow<canvas>

[method]canvas.shape: func¶

Draws a kind shape inside rect, filled with fill and outlined with stroke, antialiased.

Params¶
  • self: borrow<canvas>
  • kind: shape
  • rect: rect
  • fill: rgba
  • stroke: stroke

[method]canvas.text: func¶

Draws text with its baseline starting at at, pixel-size pixels high, in color, styled by options. Returns the text's bounding box.

The font is the first family in font-families: the fonts compiled into the component.

Params¶
  • self: borrow<canvas>
  • at: point
  • text: string
  • pixel-size: s32
  • color: rgba
  • options: text-options
Return values¶
  • rect

[method]canvas.font-families: func¶

Returns the font families the component can draw with.

Params¶
  • self: borrow<canvas>
Return values¶
  • list<string>

[method]canvas.pixel: func¶

Returns the colour of the pixel at at, or nothing when at is outside the canvas.

Params¶
  • self: borrow<canvas>
  • at: point
Return values¶
